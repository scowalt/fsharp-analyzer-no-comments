# NoComments Analyzer

An FSharp.Analyzers.SDK analyzer that enforces the no-comments policy: every comment token in F# source is an error unless a policy exemption applies.

## Language

**Comment**:
Any comment token in the F# grammar: `//`, `///`, `////`-and-longer, and `(* ... *)`. Determined by the lexer, never by text matching, so comment-like text inside string literals is not a Comment.
_Avoid_: remark, annotation, note

**Violation**:
A Comment covered by no Exemption. Each Violation is reported at error severity.
_Avoid_: hit, finding, warning

**Exemption**:
One of the four policy categories under which a Comment or file escapes reporting: Machine-read directives, Generated files, Shebangs, and SQL migrations (out of scope for F#).
_Avoid_: exception, allowlist entry

**Machine-read directive**:
A Comment whose body begins, after optional whitespace, with a Directive prefix. Exempt because a tool consumes it.
_Avoid_: pragma, magic comment

**Directive prefix**:
A string that identifies a Machine-read directive. The set of Directive prefixes is the Baseline plus any repo Config additions.

**Baseline**:
The compiled-in floor of Directive prefixes and Generated globs. Repo Config can extend the Baseline, never shrink it.

**Config**:
A repo's `no-comments.json` file, which appends Directive prefixes and Generated globs to the Baseline.

**Suppression directive**:
The SDK-defined `fsharpanalyzer:` ignore comment family, adopted as the policy's emergency escape hatch. It is itself a Machine-read directive, and each use is a bug to burn down.
_Avoid_: disable comment, nolint

**Generated file**:
A file exempt in full, either because a Generated marker appears in its First comment block or because its path matches a Generated glob.

**Generated marker**:
`@generated` or `<auto-generated` (covering `<auto-generated>`, `<auto-generated/>`, and `<auto-generated />`), matched case-insensitively.

**Generated glob**:
A path pattern that marks every matching file as a Generated file.

**First comment block**:
The first contiguous run of comment tokens appearing before any non-comment, non-whitespace token in a file. A Shebang does not interrupt it.

**Shebang**:
Line 1 of a file beginning `#!`. Exempt.
